# phototag

**键盘流照片打标 + 成片画廊** —— 给按天存储的大量 JPEG+RAW 照片库用(围绕 Sony A 系列工作流设计,但任何"JPEG+RAW 成对"的相机都适用)。

[English](README.md) · 中文

tag 存在每个天文件夹里的一个小小的 `phototags.json`(纯 JSON、原子写入 —— 照片搬到哪,tag 就跟到哪)。没有数据库、没有云、没有构建步骤。服务器只绑定 `127.0.0.1`。

## 你会得到什么

- **打标器(tagger)** —— 全键盘、一键一张,在三个维度(状态 / 类型 / 质量)上快速打 tag,带自动前进、过滤器、总览网格、捏合/滚轮缩放。看的是 JPEG;纯 RAW 库也能用。
- **画廊(gallery)** —— 上千张带 tag 照片的快速浏览器:时间线、带实时计数的 tag 筛选、灯箱(可在里面改 tag)、多选、批量导出,以及一个会**把竖屏自动拼图铺满宽屏**的全屏幻灯片。
- **工具(tools)** —— 四个批处理,统一"先预览、后确认"的图形界面:收集成片、给 Lightroom 导出 XMP、回填 tag、清扫废片。**任何操作都不删除文件。**
- **light 版** —— 单个 HTML 文件,在 Chrome/Edge 里直接跑,完全不需要 Python(Windows 或借来的机器上很好用)。

全部由 Python 标准库 + 原生单文件 HTML/CSS/JS 写成。没有框架、没有 `npm`、没有外部服务。

## 平台支持

| 版本 | macOS | Windows | Linux |
|---|:--:|:--:|:--:|
| **v2 服务器版**(打标 + 画廊 + 工具) | ✅ | ❌(见下) | ⚠️ 需替换 `sips` |
| **light 版**(单文件打标器) | ✅ | ✅ | ✅ |

**为什么 v2 服务器版目前只支持 macOS:** 缩略图、RAW 内嵌预览的提取、RAW 全尺寸解码,全都调用 **`sips`**(苹果自带的图像工具)。Python 本身是跨平台的,`sips` 不是。Windows 上没有 `sips`,所以缩略图、画廊、RAW 预览都无法工作。

**Windows 上现在就能用的:** 用 **[light 版](#light-版)** —— 用 Chrome 或 Edge 打开 `light/tagger.html`,选择照片文件夹,就能打 tag。零安装。限制:只显示 **JPEG**(无 RAW 预览),没有画廊/工具/缩略图条。

**想在 Windows/Linux 跑完整 v2?** 把 `v2_server/serve.py` 里的 `sips` 调用(`ensure_thumb`、`ensure_arw_preview`、`ensure_arw_full`)换成跨平台解码器,比如 **Pillow** 或 **ImageMagick**。这是唯一与系统绑定的依赖,其余服务器代码都是可移植的。欢迎 PR。

## 环境要求

- **macOS**,自带的 **Python 3** 和 **`sips`**(都是预装的 —— 不用装任何东西)。
- **可选:** [`exiftool`](https://exiftool.org)(`brew install exiftool`)。装了的话,RAW 内嵌预览秒开;没装则回退到较慢的 `sips` 解码。
- 任意现代浏览器用于界面。**light 版**需要 Chrome 或 Edge(它用 File System Access API)。

## 快速开始

**需要一台 Mac。** Python 3 和 `sips` 都是 macOS 自带的,所以不用先装任何东西。(Windows 或 Linux 请改用 [light 版](#light-版)。)

### 1 · 打开「终端」App

按 **⌘(Command) + 空格**,输入 **终端**(或 Terminal),回车。会打开一个文字窗口 —— 下面的命令就复制粘贴进这个窗口,每一段贴完按回车。

### 2 · 下载 phototag

```bash
git clone https://github.com/tREeFrOGcoder/Photo-Tagger-Gallery.git
cd Photo-Tagger-Gallery
```

- **第一次**运行 `git` 时,macOS 可能弹出*「安装命令行开发者工具」* —— 点**安装**,装完再把这两行跑一遍。
- 如果你配了 SSH key,也可以用 `git clone git@github.com:tREeFrOGcoder/Photo-Tagger-Gallery.git`。

### 3 · 启动

```bash
python3 v2_server/serve.py --open
```

浏览器会自动打开 phototag。(没自动开就手动访问 **http://127.0.0.1:8787**。)你会落地在**打标器**;右上角有个小切换器,一点就到**画廊**和**工具**页。

### 4 · 指向你的照片

在页面里点 **📁 换目录**,浏览到装着**各个天文件夹**的那一层,确认。搞定 —— 可以开始打 tag 了。随时按 **`H`** 查看全部键位。

照片库应当是**每天一个文件夹**(`phototags.json` 由 phototag 自己创建,不用你管):

```
你的照片文件夹/
├── 2026.01.01/           ← 一个"天"文件夹(文件夹名字被当作日期)
│   ├── DSC00001.JPG
│   ├── DSC00001.ARW      ← 可选的 RAW 伴生文件
│   └── phototags.json    ← 由 phototag 创建和维护
├── 2026.01.02/
│   └── ...
```

### 停止与再次启动

- **停止:** 点一下终端窗口,按 **`Ctrl + C`**。
- **下次再用:** 打开终端,`cd Photo-Tagger-Gallery`,再跑一遍 `python3 v2_server/serve.py --open`。

### 顺手的参数(都可选)

| 参数 | 作用 |
|---|---|
| `--root "/path/to/photos"` | 启动就打开指定的库(跳过第 4 步)。必须在 `/Volumes` 或家目录之下。 |
| `--port 9000` | 换端口(默认 `8787`)。 |
| `--open` | 帮你自动打开浏览器(上面用到了)。 |

不想一直开着终端,就挂后台:

```bash
nohup python3 v2_server/serve.py >/dev/null 2>&1 &
# ……或者在 tmux/screen 窗口里跑着。
```

## tag 模型

每张照片可以带最多三个 tag。每个维度都可以不打 —— 拿不准就留 **未定**。左手管全部三个;**同一个键再按一次 = 取消**那个维度。

| 维度 | 键 | 取值(界面 · 代码) | 含义 |
|---|---|---|---|
| **类型** | `Q W E R T` | 风景 `scenery` · 动物 `animal` · 人像 `portrait` · 昆虫 `insect` · 美食 `food` | 昆虫、美食单列 —— 因为处理/外发方式不同。 |
| **状态** | `A S D` | 直出 `sooc` · 大修 `edit` · 废片 `trash` | 直出 = JPEG 即成片。大修 = 保留 RAW、进 Lightroom。废片 = JPEG+RAW 都该清(工具只**移动**,绝不删除)。 |
| **质量** | `Z X` | 绝美 `best` · 普通 `normal` | "绝美"与是否直出无关。`best` 显示一个 ★。 |

每个取值都有固定颜色,在各处一致使用(直出绿、大修蓝、废片红、绝美黄……)。

**第一遍建议:** 只打**状态**、开着自动前进 —— 一键一张,飞快。然后用过滤器把废片藏起来,再淡定地打第二遍类型/质量。

## 打标器页

`/tagger` —— 全键盘打标界面。你看的是全尺寸 JPEG,飞速过片。

```
┌─ 侧栏 (250px) ─────┬─ 照片舞台 ─────────────────────────────┐
│ 打标·画廊·工具 切换 │ [tag 徽章]                    [缩放%]  │
│ 📁 根目录名   (O)  │                                       │
│ ── 过滤 ──         │                                       │
│  类型 / 状态 / 质量 │             (当前照片)                │
│ ── 天列表 ──       │                                       │
│  2026.01.02  12/40 │                             [加载圈]  │
│  2026.01.01  ▓▓░ 8 │  [缩略图条 —— Tab]                    │
│ 页脚: N 天         │  HUD: 文件 · 12/40 · 键帽 · 已保存     │
└────────────────────┴───────────────────────────────────────┘
```

### 各面板

- **侧栏(左)。** 顶部:**页面切换器**(`打标 · 画廊 · 工具`)、当前**根目录名**(点 `📁 换目录` 或按 `O` 换)、**过滤**面板。下面是**天列表** —— 最新在上,每行显示 `已打 / 总数` 和一条绿色进度条。页脚显示全库总数。
- **照片舞台(中)。** 黑底上的当前 JPEG。叠层:**tag 徽章**(左上,你打了什么就显示什么彩色小片)、**缩放 %** 药丸(右上,仅缩放时)、**加载圈**(右下,例如 RAW 解码时)。
- **缩略图条。** 附近照片的横向胶片条;`Tab` 开关。
- **HUD(底栏)。** 文件名(ARW 带 `RAW·预览` 徽章)· 位置 `12 / 40`(筛选时加 `· 筛中 N 张`)· 天名 · 中间一排**可点击的键帽**(当前 tag 会用它的颜色点亮)· **自动前进**指示 · **保存状态**指示(`已保存` / `保存中…` / `重试中`)。

### 过滤面板(第二遍神器)

每个维度一行,每个取值一个小片,外加一个 **未定** 片。**点一个片来循环切换:**

1. 第一下 → **✕ 不看**(隐藏/跳过这些),
2. 第二下 → **✓ 只看**(只显示这些),
3. 第三下 → 取消。

维度内"只看"是"或",维度间是"且"。翻页(空格 / 方向键 / `N` / 自动前进)只在匹配的照片间移动;被过滤掉的照片在缩略图条和网格里变暗但仍可点。过滤条件会跨会话记住。

*经典用法:* 第一遍全速 `D` 标废片 → 点一下**废片**片切到 `✕` → 废片从翻页里消失 → 淡定地打剩下的类型/质量。

### 总览网格 —— `G`

按 `G` 打开当天的整面接触印相表。每格显示状态点、绝美 ★、类型标签。方向键移动选择,`N` 跳到下一张未打,`Enter`/点击打开那张,`Esc`/`G` 关闭。

### 缩放与平移 —— `.`

`.` 在 100% ↔ 适应之间切换。也可以**触控板捏合**或**鼠标滚轮**任意倍率缩放(跟随指针位置)。放大时:双指滚动 / 拖拽 / 方向键平移。对 RAW 文件,放大会自动换成全尺寸解码,真正数毛。

### 键位速查(打标器)

| 键 | 作用 |
|---|---|
| `Q W E R T` | 类型:风景 / 动物 / 人像 / 昆虫 / 美食(同键再按 = 取消) |
| `A S D` | 状态:直出 / 大修 / 废片 |
| `Z X` | 质量:绝美 / 普通 |
| `Space` · `J` | 下一张(在过滤范围内) |
| `K` | 上一张 |
| `←` `→` | 上/下一张 —— 放大时则为**平移** |
| `↑` `↓` | 平移(仅放大时) |
| `U` · `⌘Z` | 撤销(跳回那张);`⇧U` · `⌘⇧Z` = 重做 |
| `⌫` | 清空当前照片**全部** tag |
| `F` | 「打完状态自动下一张」开关(默认开) |
| `N` | 跳到下一张没打状态的照片 |
| `.` | 100% / 适应缩放切换 |
| `Tab` | 显示/隐藏缩略图条 |
| `G` | 总览网格 |
| `[` · `]` | 上一天 / 下一天 |
| `H` · `?` | 帮助 |
| `O` | 换根目录 |
| `Esc` | 退出缩放 / 关网格 / 关弹窗 |

## 画廊页

`/gallery` —— 全部带 tag 照片的可滚动**时间线**,最新天在上,用来浏览、筛选、选择、导出、放幻灯片。

```
┌ 根目录 · 换目录 · 匹配 320/1200 ·  [搜索] [▶ 幻灯片] [导出…] · 切换器 ┐
│ 过滤:  状态[…] 类型[…] 质量[…] 时间[全部|近7|近30|近90]   ✕ 清除     │
├───────────────────────────────────────────────────────────────────────┤
│ 2026.01.02 · 40 张 ·  去打标 ↗   全选本天                               │
│  [▦][▦][▦][▦][▦][▦][▦]  ← 小图:状态点 · ★ · 类型标签 · ✓ 勾选框        │
│ 2026.01.01 · …                                                         │
└───────────────────────────────────────────────────────────────────────┘
```

### 头部与过滤

- **头部:** 根目录名、`📁 换目录`、匹配计数(`匹配 N / 共 M`)、**文件名搜索**、`▶ 幻灯片`、`导出当前筛选…`、页面切换器。
- **过滤小片:** 每个维度一行(状态 / 类型 / 质量),每个小片带**实时计数**(点它会匹配到多少张)。维度内多选是并集,维度间是"且"。**时间**行给 `全部 / 近7天 / 近30天 / 近90天`。`✕ 清除筛选` 一键重置。

### 小图与灯箱

每个小图是 3:2 缩略图,带状态点、绝美 ★、类型标签,以及一个**勾选框**(右下,悬停出现)。**点小图**打开**灯箱** —— 全屏查看器,和打标器同一套缩放/平移引擎。在灯箱里可以用完全相同的键位**改 tag**(`A S D`、`Q W E R T`、`Z X`、`U` 撤销)—— 很多第二遍整理就在这里做。`去打标器 ↗` 跳到打标器的那张。

### 选择与导出

- **勾选框**点击 = 选中;**Shift 点击**选中到上一张之间的全部。**Shift 点小图本体**也是区间选(不打开灯箱)。
- **`全选本天`**(每天表头)选中一整天;**`全选`**选中当前筛选出的全部。
- 一旦有选中,底部浮出一条:**`已选 N 张`**、`▶ 播放选中`、`导出选中…`、`全选`、`清除`。切换筛选时选中集依然保留。
- **导出**(选中集,没选就导当前筛选)复制到目标文件夹,**按天建子文件夹**,同名同大小的跳过,并写一份对应的 `phototags.json` 让 tag 随行。后台任务 + 进度条。

### 键位(画廊)

时间线:`H` / `?` 提示你点开照片进灯箱。**灯箱内:** `Q W E R T` / `A S D` / `Z X` 改 tag · `Space`/`J` 下一张 · `K` 上一张 · `←`/`→` 翻页或放大时平移 · `.` 缩放 · `U` 撤销(`⇧U` 重做)· `Esc` 先退缩放再关闭。

## 幻灯片

从 `▶ 幻灯片`(播当前筛选)或 `▶ 播放选中`(播选中集)进入。**真全屏**(黑底),把照片装进一"屏"一"屏":竖屏会**自动拼图**并排铺满宽屏,横屏保留侧边,所有照片贴满屏高、之间留细黑缝。普通 16:9 / 16:10 屏每屏 **1–2 张**(带鱼屏更多)。

**控制**(按一下 `Esc` 调出控制栏 —— 默认隐藏,看片时不会乱弹):

- **⏮ ⏸ ⏭** —— 上一张 / 播放暂停 / 下一张。计数显示 **`第几屏/共几屏 · N 张`**(拼图后屏数少于照片数是正常的)。
- **打乱:** `顺序` · `按日乱`(保留天序、天内打乱)· `全乱`。
- **适配:** `适应`(完整显示、留黑边)· `铺满`(每格 cover 裁剪铺满,留细黑缝)。
- **停留:** `2s` · `8s`(默认)· `30s` · 或在内联框里填任意秒数。
- **淡变:** `硬切`(无淡入淡出)· `0.3s`(默认)· `0.6s` · 或内联填任意秒数。淡出→全黑→淡入,不重叠。
- **🔒** 重新锁定并回全屏 · **✕** 退出。

**锁定 / Esc 流程:** 开播即**锁定**且全屏。按一下 **Esc** → 浏览器退出全屏、控制栏出现(幻灯片继续放)。**再按 Esc** → 退出。点 **🔒** 重新锁定。

**键位:** `Space` 播放/暂停 · `→`/`J` 下一张 · `←`/`K` 上一张 · `Esc` 解锁 → 退出。

**深链:** 打开 `/gallery?ss=1` 直接自动播放。加 `&fill=1` 以铺满开场,`&fade=<毫秒>` 设淡变时长(如 `&fade=600` 更柔、`&fade=0` 硬切)。

*原理:* 照片用全分辨率显示;停留期间预解码接下来约 5 张,每次切换都等真正的 `decode()` 完成再淡入,所以淡入顺滑、中间黑屏极短。方向从缩略图预先量好,拼图在加载前就算对。

## 工具页

`/tools` —— 四个批处理做成卡片。**每张卡片都先预览(只读),确认了才执行。** 路径用文件夹浏览弹窗选。除了废片清扫,都不动你的源库原图。三页共用一个后台进程,右上角切换器互跳。

| 卡片 | 徽章 | 作用 | CLI 等价 |
|---|---|---|---|
| **成片收集** | 复制 | 按 tag 条件把照片复制进成片目录(tag 随行,同名同大小跳过)。默认条件:状态 = 直出。 | `collect_picks.py` |
| **XMP 导出** | 写 sidecar | 给每个大修 RAW 写一份 Lightroom 可读的 `.xmp`(色标 + 关键词)。**绝不覆盖**已有 `.xmp`。 | `export_xmp.py` |
| **Tag 同步** | 补空白 | 认领 Lightroom 导出到成片、但还没 tag 的成品:按 **天 + 主名**回源库补 tag。**只补空白,绝不覆盖。** | *(仅网页版)* |
| **废片清扫** | 移动 | 把 `status=废片` 的 JPEG+RAW+伴生文件移进 `<源库>/_trash_bin/`。**只移不删** —— 可以捞回来。 | `sweep_trash.py` |

**每张卡片的流程:** 填路径 → **预览** 显示到底会发生什么(数量、大小、按天明细、任何警告)→ 确认按钮只在"确实有事可做"时才可点 → **确认** → 进度条跑任务(废片清扫会再二次确认)。

## light 版

`light/tagger.html` —— 整个打标器塞进**一个 HTML 文件**,不需要服务器。用 **Chrome 或 Edge** 打开,点 **选择照片根目录**,选你的库文件夹。它用浏览器的 File System Access API 读照片、把 `phototags.json` 直接写进每个天文件夹(带一份 `localStorage` 镜像做备份),并记住你的文件夹方便下次。

界面和 **键位与 v2 完全相同**,区别在于:

- **仅 JPEG** —— 无 RAW 预览、无全尺寸解码。
- 缩略图条和总览网格显示**文件名卡片**(名字 + 状态点 + ★ + 类型标签),不是图片缩略图(没有缩略图服务器)。
- 没有画廊、没有工具、没有页面切换器。
- 需要 Chrome/Edge(Safari/Firefox 没有这个 API)。这是 **Windows** 上的推荐路径。

在运行中的 v2 服务器上也能从 `/light` 访问它。

## 命令行工具

工具页就是它们的图形界面;脚本本身也在(都默认 **dry-run**,只打印 —— 加 `--apply` 才真的执行)。

```bash
# 清扫废片 → <源库>/_trash_bin/<天>/(移动 JPEG+RAW+伴生;绝不删除)
python3 tools/sweep_trash.py --root "/path/to/photos"
python3 tools/sweep_trash.py --root "/path/to/photos" --apply

# 按 tag 条件把成片收集进目标目录
python3 tools/collect_picks.py --root "/path/to/photos" --dest "/path/to/selects" --where status=sooc
python3 tools/collect_picks.py --root "/path/to/photos" --dest "/path/to/selects" --where status=sooc quality=best --apply

# XMP 桥:给大修 RAW 写 .xmp,Lightroom「添加」导入后按色标筛
python3 tools/export_xmp.py --root "/path/to/photos"          # dry-run
python3 tools/export_xmp.py --root "/path/to/photos" --apply  # 绝不覆盖已有 .xmp
```

Lightroom 导入配方见 [`docs/LIGHTROOM.md`](docs/LIGHTROOM.md)。

**安全原则:任何工具都不删除任何东西。** 废片只是被**移进** `_trash_bin`;确认无误后由你自己清空。

## 数据、存储与安全

- **tag** 存为每个天文件夹里的 `phototags.json` —— 一个以文件名为键的小 JSON。搬/复制天文件夹,tag 跟着走。
- **写入很安全:** 原子写 + `fsync`、首次写前做 `.bak` 备份、损坏文件自动自愈,以及一份全局只追加的流水日志 `~/Library/Application Support/phototag/journal.jsonl`。
- **缩略图缓存**在 `~/Library/Caches/phototag/`。可随时整体删除,会自动重建;里面没有任何照片数据。
- **RAW(ARW):** JPEG+RAW 成对时看 JPEG。孤 RAW(如纯 RAW 机身)用内嵌 ~1920px 预览显示(秒开),放大时全尺寸解码(首次几秒,之后走缓存)。
- 服务器只绑定 **`127.0.0.1`**,并拒绝 `/Volumes` 或家目录之外的任何路径。

## 成片工作流

一套建议的流水线(四个批处理步骤都在工具页,也有 CLI 脚本)。心智模型:**两个库 + 一次 Lightroom 绕道**。

1. **打标第一遍**:定状态、开自动前进(一键一张);用过滤器藏掉废片,再打类型/质量。
2. **废片清扫** → 移进 `_trash_bin`(可捞回)。
3. **直出成片** → **成片收集**(条件 = 直出)把它们连 tag 一起复制进成片目录 —— 或用画廊的「导出当前筛选」。
4. **大修** → **XMP 导出**给大修 RAW 写 sidecar → Lightroom 按色标聚组修 → 导出时**保持原文件名**进成片目录。
5. **Tag 同步** → 把 tag 回填到那些 Lightroom 导出的成品上(按天 + 主名;只补空白)。
6. **浏览/发布:** 画廊指向成片目录,按日期/tag 切组、导出子集、放幻灯片。

## 常见问题

- **`sips: command not found` / 没有缩略图。** 你不在 macOS 上 —— v2 服务器需要 `sips`。用 [light 版](#light-版),或把 `sips` 换成 Pillow/ImageMagick。
- **某天只有 RAW 没有 JPEG。** 支持 —— 孤 RAW 显示内嵌预览、可打 tag、放大全尺寸解码(仅 v2;light 版只支持 JPEG)。
- **`._` 开头的文件是什么?** exFAT 上 macOS 的元数据垃圾;所有工具都会自动忽略。
- **缩略图缓存在哪?** `~/Library/Caches/phototag/` —— 可整体删除。
- **tag 会被写坏吗?** 原子写 + `.bak` 备份 + 自愈 + 流水日志(见[数据、存储与安全](#数据存储与安全))。
- **端口被占用 / 想换端口。** `--port 9000`。
